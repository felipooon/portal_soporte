# Reglas del Proyecto (portal_soporte)

## Git Commits
- NUNCA hagas `git commit` ni `git push` de forma automática tras modificar el código.
- SIEMPRE explica los cambios primero y espera a que el usuario valide que el código funciona y dé su aprobación explícita antes de agrupar los cambios en un commit.
- El objetivo es mantener el historial de Git limpio y evitar llenarlo de commits de "prueba y error".
